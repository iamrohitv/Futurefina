# @futurefina/web

Next.js 16 advisor console for the Futurefina WhatsApp CRM. The app currently
uses typed fixtures; Phase 5 replaces them with the PostgreSQL-backed API.

## Run

From the repository root:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Verify

```bash
npm run lint
npm run typecheck
npm run test
npm run build
npm run test:e2e
```

Project documentation, design tokens, and decision records live in
[`.github/docs`](../../.github/docs).
